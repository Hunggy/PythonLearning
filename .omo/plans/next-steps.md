## 方向一：Web开发（Flask）🔥 推荐首先

### 项目：错题本 Web 应用
**目标**：把现有的 `wrong_notes.md` 做成可搜索、分类的 Web 应用  
**用到已有知识**：SQLite（sqlite_db/）、文件读写（data_io/）  
**新知识**：Flask 框架、HTML/CSS 基础、Jinja2 模板

#### 学习步骤
1. **Flask 入门**（1-2小时）
   - 安装 Flask：`pip install flask`
   - 创建最小应用：路由、视图函数、模板渲染
   - 参考：Flask 官方教程 https://flask.palletsprojects.com/tutorial/

2. **数据库设计**（1小时）
   - 创建 `wrong_notes.db`，表结构：
     - `id` INTEGER PRIMARY KEY
     - `question` TEXT（题目）
     - `category` TEXT（分类：类对象/文件/可视化/SQLite/tkinter 等）
     - `wrong_answer` TEXT（你的错误答案）
     - `correct_answer` TEXT（正确答案）
     - `note` TEXT（备注/理解）
     - `created_at` TIMESTAMP
   - 把 `wrong_notes.md` 的内容导入数据库

3. **核心功能**（2-3小时）
   - 列表页：显示所有错题，支持按分类筛选
   - 详情页：查看单题详情
   - 搜索功能：按关键词搜索题目
   - 随机练习：随机抽取 10 题做测试

4. **界面美化**（1-2小时）
   - 用 Bootstrap 快速美化（CDN 引入，不用学 CSS）
   - 响应式布局，手机也能用

#### 成功标准
- [ ] 能在浏览器访问 `http://localhost:5000`
- [ ] 能按分类查看错题
- [ ] 能搜索题目
- [ ] 能随机出题练习
- [ ] 界面整洁，手机可用

#### 文件结构建议
```
web_wrong_notes/
├── app.py              # Flask 主程序
├── init_db.py          # 初始化数据库+导入数据
├── templates/
│   ├── base.html       # 基础模板（导航栏、页脚）
│   ├── index.html      # 错题列表
│   ├── detail.html     # 错题详情
│   └── practice.html   # 随机练习
└── wrong_notes.db      # 数据库文件
```

## 方向二：数据分析与可视化

### 项目：考试成绩分析报告
**目标**：分析你的刷题数据，生成个性化学习报告  
**用到已有知识**：matplotlib/numpy（viz/）、Excel 读取（excel/）  
**新知识**：pandas 数据处理、更高级的可视化

#### 学习步骤
1. **pandas 入门**（2小时）
   - 安装：`pip install pandas`
   - 核心概念：DataFrame、Series
   - 读取数据：Excel/CSV/JSON
   - 参考：pandas 官方 10 分钟入门 https://pandas.pydata.org/docs/user_guide/10min.html

2. **数据准备**（1小时）
   - 读取 `成绩表.xlsx` 或手动整理的刷题记录
   - 清洗数据：处理缺失值、统一格式
   - 计算衍生指标：正确率、每题耗时、分类得分率

3. **分析维度**（2-3小时）
   - 总体分析：平均分、最高分、分数分布
   - 分类分析：5 大考点的得分率对比（雷达图）
   - 时间分析：刷题进度趋势（折线图）
   - 薄弱环节：错误率最高的知识点

4. **生成报告**（1-2小时）
   - 用 matplotlib 生成图表
   - 汇总成 HTML 报告或 PDF
   - 给出个性化学习建议

#### 成功标准
- [ ] 能用 pandas 读取并处理 Excel 数据
- [ ] 生成至少 3 种图表（柱状图、雷达图、折线图）
- [ ] 报告包含：总体分析、分类分析、薄弱环节、学习建议
- [ ] 图表清晰美观，有标题和标签

## 方向三：自动化脚本进阶

### 项目：智能文件整理器 Pro
**目标**：增强 `folder_clear/`，支持更多文件类型、自动重命名、定时任务  
**用到已有知识**：os/shutil（folder_clear/）、字符串处理（rename/）  
**新知识**：文件类型识别、schedule 定时、日志记录

#### 学习步骤
1. **文件类型识别**（1小时）
   - 用 `magic` 或文件头识别真实类型（不依赖扩展名）
   - 安装：`pip install python-magic`（Windows 需额外配置）

2. **智能重命名**（1-2小时）
   - 读取图片 EXIF 日期、文档创建时间
   - 按日期重命名：`2026-09-01_照片.jpg`
   - 处理重名：自动加序号

3. **定时任务**（1小时）
   - 用 `schedule` 库设置定时整理
   - 或用系统任务计划程序（Windows Task Scheduler）

4. **日志与撤销**（1小时）
   - 记录每次操作到日志文件
   - 实现撤销功能：恢复到整理前的状态

#### 成功标准
- [ ] 支持至少 10 种文件类型自动分类
- [ ] 能按拍摄/创建日期重命名
- [ ] 能设置定时自动整理
- [ ] 有操作日志，支持撤销

## 方向四：Python 高级特性

### 项目：实用装饰器与生成器合集
**目标**：通过实际项目学习高级特性，而不是纯理论  
**用到已有知识**：函数、类、文件操作  
**新知识**：装饰器、生成器、上下文管理器、异步编程

#### 学习步骤
1. **装饰器实战**（2小时）
   - 计时器装饰器：统计函数运行时间
   - 缓存装饰器：`functools.lru_cache` 实现
   - 重试装饰器：网络请求失败自动重试
   - 登录验证装饰器（为 Web 开发铺垫）

2. **生成器实战**（1-2小时）
   - 逐行读取大文件（内存友好）
   - 生成斐波那契数列
   - 管道式数据处理

3. **上下文管理器**（1小时）
   - 自定义 `with` 语句：数据库连接、文件锁
   - 用 `contextlib` 简化

4. **异步编程入门**（2-3小时）
   - `asyncio` 基础：协程、事件循环
   - 并发请求多个网页（`aiohttp`）
   - 对比同步 vs 异步的性能差异

#### 成功标准
- [ ] 能写出至少 3 个实用装饰器
- [ ] 理解生成器的惰性求值优势
- [ ] 能用 `with` 管理资源
- [ ] 能用 `asyncio` 并发执行任务
